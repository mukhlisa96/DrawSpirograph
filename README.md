
##  Turtle Spirograph with Random Colors

This Python project uses the **turtle** module to create a **colorful spirograph**. The turtle draws overlapping circles with **random RGB colors**, producing a vibrant, circular pattern.

---

###  How It Works

* A turtle named `tim` draws circles repeatedly while **rotating slightly** after each circle.
* The `random_color()` function generates a **new RGB color** for each circle.
* The **size of the gap** between circles determines the number of circles in the spirograph.
* The turtle moves at **fastest speed** for quick drawing.

---

###  Concepts Used

* Python `turtle` graphics
* RGB color system (`t.colormode(255)`)
* Random number generation for dynamic colors
* Loops for repetitive drawing
* Angles and headings to create circular patterns
* Functions to organize code (`random_color()` and `draw_spirograph()`)
